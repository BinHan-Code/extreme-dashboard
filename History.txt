--------------------------------------------------------------------------------
ARCHITECTURE SUMMARY
--------------------------------------------------------------------------------

Data layer
  All product and competitive data is static JSON in data/:
    data/products.json          — product catalog (id, name, category, specs, etc.)
    data/competitive.json       — vendor comparison data
    data/switching-matrix.json  — generated from .xlsx via scripts/
    data/ap-matrix.json         — generated from .xlsx via scripts/
    data/urls.txt               — Design topic reference URLs (one per line)

Pages (app/)
  /                   — Home: category tiles, Security Advisory widget, Google search
  /catalog            — Product catalog: fuzzy search (Fuse.js), filters, matrix modals
  /competitive        — Competitive intelligence comparison table
  /manga              — Fabric Connect SPB manga reader (static HTML chapters)
  /chat               — Fabric Connect AI chatbot (calls external RAG API)
  /manager            — Manager-only page view analytics + CSV download

API routes (app/api/)
  /api/security-advisory  — Proxies Extreme Networks RSS feed; 1h cache
  /api/design-search      — Reads data/urls.txt, fetches each URL server-side,
                            returns title + excerpt per article; 1h cache
  /api/track              — Records page views to data/pv/
  /api/pv                 — Manager-only: returns page view JSON for download

Components (components/)
  Navbar.tsx               — Top nav with language toggle, dark mode, chat CTA
  SecurityAdvisoryWidget.tsx — Latest 2 security advisories from Extreme RSS feed
  ProductCard.tsx          — Card used in the catalog grid
  ComparisonTable.tsx      — Used in /competitive
  SwitchingMatrix.tsx      — Modal overlay for switching product matrix
  APMatrix.tsx             — Modal overlay for AP product matrix
  SearchBar.tsx            — Reusable search input
  ThemeProvider.tsx        — Dark/light mode context
  PageViewTracker.tsx      — Client-side page view recorder

Context & library
  context/LanguageContext.tsx — React context; provides { lang, setLang, t }
  lib/translations.ts         — All EN + JA UI strings
  lib/chatApi.ts              — Chat API client for the external RAG service

External service
  https://fabric-connect-rag.up.railway.app/chat
    POST { question, topic, mode } -> answers with sources from RAG pipeline
    Modes: knowledge_search | design | troubleshooting
